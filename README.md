# Evroopt Budget

Семейный бюджет и учёт закупок (Евроопт).

- План походов + аппрув
- WMS (учёт дома)
- Факт (что куплено и по какой цене)
- Аудит по месяцам
- Мастер: генерация промта для ИИ + импорт ответа
- Роли: admin (родитель) / buyer (сын)

Деплой: https://paaladin.github.io/evroopt-web/

Backend: Supabase (см. `sandbox`).
